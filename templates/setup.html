Quick setup

  1. Start Oracle Database Free or XE and open its pluggable database.
  2. Run the scripts in the sql/ folder in the order shown in README.md.
  3. Copy .env.example to .env and set the Oracle connection details.
  4. Restart python app.py and refresh this page.
